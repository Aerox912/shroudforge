# Shroudweave experiment branch

This branch preserves unfinished Shroudweave work against ShroudForge 1.7.7.
It is an untested source checkpoint: it has no build, gameplay, or multiplayer
acceptance, and it is not ready for a pull request or release. Nothing in this
branch authorizes activation or installation.

## Parser provenance

The `kfc-parser` submodule points to the Aerox912 fork of
`bonsaibauer/kfc-parser` at a fixed revision, without branch tracking. The
parser retains Brabb3l's upstream credit and its `GPL-3.0-or-later` license.
ShroudForge owns the integration; it does not replace the parser's provenance.

## Preserved scope

EarlyProbe, world-observation, and Auto Loot catalog changes are preserved here
as unfinished experiments. Their presence does not resume paused feature work,
qualify them for the tested port, or establish compatibility. Other paused mod
work remains paused until separately resumed.

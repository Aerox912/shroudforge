# Prepared Shroudweave generator

The prepared generator is a developer-only caller of ShroudForge's pregame asset API. It runs an explicitly selected pregame mod set against a read-only asset input root and a separate mod/config environment. Generated files remain in a private output stage. The API does not publish them, change the installed game, activate runtime behavior, or integrate with the installer.

The caller requires disjoint environment, asset-input, and output roots. It snapshots and rechecks declared inputs, refuses an existing transaction or output stage, and records a prepared-only marker that the ordinary commit, recovery, and abort paths refuse. The schema-2 receipt also carries the canonical source DAT name and content-stamp map, which the caller rechecks after generation before accepting the stage. A final consumer must revalidate that map immediately before use; the receipt does not lock source files after return. The source KFC and resource mappings remain in the generated index. Existing source DAT files remain in the consumer's overlay view; the generated stage contains only generated DAT slots. Before generation, the caller rejects case aliases, noncanonical decimal padding, non-files, and out-of-range source DAT names.

The parser submodule is pinned at `ddeb44ecd44d80d1964fcc0d1c3fff29a1c49d54`. Its `KFCWriter::new_generated_incremental` API scans physical source DAT slots before creating outputs, reserves occupied slots even when the source index does not reference them, and appends only new output data. Source DAT files are not copied into the generated stage. The caller tests build a small composite view from generated files plus source DAT files to verify that retained and new mappings resolve together.

The caller's producer identity is supplied as `HD_PREPARED_SOURCE_CLOSURE` only after Delivery computes it from the committed source. There is no checked-in placeholder identity. Run the focused caller tests with `dev/tests/run_workspace_tests.ps1` after setting that value from the current Delivery receipt.

This remains experimental and unaccepted for use. No standard startup, installation, activation, or publication path invokes it. The caller and parser have not been validated as a complete prepared-generation release, and this work does not establish PR readiness. Runtime and activation follow-up remains paused pending separate ownership and review.
